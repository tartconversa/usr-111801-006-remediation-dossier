# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕整改材料的闭环与撤销血缘开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

整改复核域区分三个层面：整改要求项（限期通知中的每个原问题，带设施/服务/安全类别与序号）、材料版本（按要求项累积的不可变证据链，补交不删除被退回原件）、复核决定（审核者针对具体材料版本给出的 pass/return 判断及理由，可软撤销并留痕）。要求项与全案结论不是存储状态，而是由当前有效复核实时推导：任一要求项缺少有效通过即构成发布缺口，撤销复核会重新打开缺口，已生成的拟发布快照保留并可校验是否仍被当前结论支持。
